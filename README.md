# OxyWalls - Smart Air Purifier System

OxyWalls is an intelligent air purification system built using Arduino. It uses:
- DHT11 for temperature and humidity
- MQ135 for gas detection (CO2, NH3)
- PM2.5 dust sensor
- OLED display for real-time air quality updates
- Auto fan control via relays based on pollution levels

This project improves air quality in enclosed spaces by smartly managing exhaust fans and indicating air status visually.
